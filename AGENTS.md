Build the core structure and functional requirements for a professional portfolio web application with the following sections and features:

1. Navigation Bar (Navbar):
   - Fully responsive navbar providing smooth and easy navigation across all sections of the portfolio.

2. About Me Section:
   - Detailed personal introduction covering the programming journey, preferred types of work, hobbies/interests outside of coding, and personality highlights.

3. Skills Section:
   - Visually appealing graphical display of skills, properly categorized (e.g., Frontend, Backend, Tools).

4. Educational Qualification:
   - Comprehensive academic background details (for education above HSC).

5. Experience Section:
   - Dedicated section for professional experience (if applicable).

6. Projects Section (At least 3 Projects):
   - Card-format grid showcasing top projects. Each card must feature: Project Name, Project Image, and a "View More / Details" button.
   - Detailed project view/modal/page triggered by the button containing:
     * Main technology stack used
     * Brief description
     * Live project link
     * GitHub repository link (client-side)
     * Challenges faced while developing the project
     * Potential improvements and future plans

7. Contact Information:
   - Direct contact options including Email Address, Phone Number, and optional WhatsApp number.

8. Footer:
   - Simple and elegant footer component.

9. General Technical & Responsiveness Requirements:
   - Ensure full responsiveness across all devices (desktop, laptop, tablet, and mobile).
   - Write clean, modular, and well-structured code.
